# Notebooks

Start with [01_dashboard_demo.ipynb](01_dashboard_demo.ipynb): it is offline and
uses the committed fictional dataset.

The remaining numbered notebooks are research review tools. They require their
corresponding ignored local datasets and preserve the distinction between AI
suggestions and verified human judgments. They are not executed automatically.
Run Jupyter from the repository root. Do not commit cell outputs, advertisement
text, credentials, widget state or local filesystem paths.

Early API exploration and heuristic classification are in [archive/](archive/).
Those experiments do not define the current Step 7 dashboard inclusion policy.
Original executed notebook copies remain in the ignored local archive.
